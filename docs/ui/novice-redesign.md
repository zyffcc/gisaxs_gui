# 给小白的 GIMaP：界面重新设计

- **Status**: 提案（2026-09-29 夜间起草，部分已实现，见第 9 节）
- **Scope**: 应用外壳、引导式流程、结果呈现、AI 副驾（可预览操作）、AI 提供方设置
- **Related**: `docs/agents/giwaxs-playbook.md`（基线 / 追查两层）、`src/gimap/features/assistant/`

## 0. 一句话

小白要的不是一排工具，而是**一条路**：从“我想知道什么”出发，程序自动走完能自动走的步骤，每一步
都给出看得见的证据和一个明确的下一步；AI 是坐在旁边的副驾，它的每个建议都是一张**能先预览、再应用、
随时撤销**的操作卡片，而不是一段文字。专家视图保留，但不再是入口。

## 1. 小白是谁，现在卡在哪

**典型用户**：研一 / 研二学生，或第一次去同步辐射线站的人。懂自己的材料（钙钛矿、聚合物薄膜、纳米颗粒），
不懂数据约化；手里是一个文件夹（CBF / TIFF / 多模块 NeXus、标样图、日志、组会 PPT）。

**他们要完成的事**：

| 任务 | 他们会怎么问 |
|---|---|
| 看薄膜里有什么晶体、朝哪个方向 | “这个样品是 face-on 还是 edge-on？” |
| 看纳米结构的尺寸和间距（GISAXS） | “颗粒多大？间距多少？” |
| 原位 / 批量：随时间、温度怎么变 | “退火过程中结晶什么时候开始？” |
| 出图、写组会 PPT、写论文方法部分 | “帮我出一张能放论文里的图” |

**现在的界面对他们的障碍**（见 `before/page_analyze_loaded.png`：打开一个没标定的 Lambda 帧）：

1. **工具平铺，没有顺序**：Open、Instrument、Geometry…、Calibrate…、Auto / GISAXS / GIWAXS、αi、Beam centre、
   Options、Auto Cuts、Export、Process with Claude…、Send to Fitting，十几个按钮同一层级。小白不知道先点哪个。
2. **死胡同**：没有几何时，只有一行 “No instrument profile … Calibrate once or enter the geometry”，右边两个空图
   写着 “No geometry yet”。程序其实能自己找标定（助手里已有），但界面没用上。
3. **术语门槛**：αi、GIWAXS / GISAXS、sector、Auto Cuts、instrument profile、q map——没有解释。
4. **看不到“测到了什么、没测到什么”**：缺失楔、探测器缝、阴影（Yuxin 数据 χ > 57° 的阴影，连基线都曾被骗）在界面上
   没有标出，小白会把伪影当结果。
5. **AI 只是一个按钮 + 一篇文字报告**：报告里的数字和图上的东西没有联系；AI 改了什么、能不能退回，看不出来。
6. **Labs 和日常功能挤在一个侧栏**：2D Prediction、Trainset、Classification 对小白是噪音。

## 2. 设计原则

1. **任务优先**：入口是“你想知道什么”，不是“选哪个工具”。
2. **一屏一个决定**：引导流程每步只问一个问题；高级选项折叠（progressive disclosure）。
3. **能自动的都自动，但要给证据**：探测器、能量、帧数、标定文件、标样、测量模式都自动识别，并用缩略图 + 质量徽章
   说明（“找到 LaB6+CeO₂ 标定，7 条线平均误差 0.06% ✓”）。
4. **每个数字都有含义和可信度**：d = 2π/q 自动换算；质量用三色徽章（可信 / 可用 / 存疑）；点一下看它怎么算出来的、
   在图上的哪里。
5. **先看图，再看表**：所有分析都在图上有叠加层——扇区、环、缺失楔、阴影、地平线，测不到的地方用斜线标出。
6. **放心试**：任何改动都能预览、撤销；会话自动保存；不在数据旁边写文件，除非你选了导出位置。
7. **AI 是副驾，不是神谕**：它提议，你应用；它做过的每件事都在时间线上，可以一步一步撤回。
8. **没有 AI 也能用**：确定性的基线流程在本地出结果；AI 只是加解释和追查。
9. **小白和专家用同一个引擎**：引导流程只是专家视图的一层外壳；“在专家视图中打开”能看到完全相同的设置。
10. **中文优先、术语可点**：界面中英切换；每个术语悬停有一句话解释（例：“αi 入射角：X 射线擦过样品表面的角度，
    常见 0.1–0.5°”）。

        │
        ▼

## 5. AI 的“可预览操作”

### 5.1 为什么

文字建议要用户自己去找按钮、自己改参数，小白做不到，也不知道改完会怎样。操作卡片把“建议”变成
**一个具体的、可执行的、看得见后果的改动**，用户只需要判断“要不要”。

### 5.2 卡片的内容

| 字段 | 说明 |
|---|---|
| 标题 | 人话：“把面内扇区缩窄到 ±5°” |
| 为什么 | 一句话，引用证据（数字、图） |
| 改动 | 具体参数：旧值 → 新值（例：扇区半宽 10° → 5°） |
| 预览 | 改动前后的缩略图（q 图叠加层、I(q) / I(χ) 曲线）和关键数字的差异 |
| 状态 | 建议 → 预览中 → 已应用 / 已忽略 → 已撤销 |
| 按钮 | 预览、应用、忽略；应用后变“撤销” |

### 5.3 预览怎么实现（已实现，见第 9 节）

- 每个会改设置的操作（扇区、自定义扇区、q 框、帧 / 求和、测量模式、αi、强度范围）都有**逆操作**：
  应用前从状态里记下旧值，撤销时按旧值恢复。
- **预览**：临时应用 → 抓取结果（缩略图、曲线、数字）→ 恢复（`propose_operations`）。“先预览”模式下
  AI 在真实工作区里分析（界面照样跟随），结束时它改过的设置全部恢复，每个设置只留最后的净改动作为卡片，
  探索步骤、回到起点的改动和看不出效果的改动不显示；AI 对某个设置明确提了建议，这个设置就只显示建议。
  你的工作区不变，直到你点“应用”。
- **追问**：结果下面可以直接问（“为什么面内扇区几乎没有信号？”），新的一轮在同一帧、同一设置上回答，
  知道上一轮的发现，回答可以带新卡片。
- **应用**：真正执行并记下旧值；**撤销**：恢复旧值。所有操作排成时间线，可以整组撤销（“撤销 AI 的全部改动”）。
- 几何（保存仪器配置）：预览只显示新几何下的 q 图，应用前一定确认。

### 5.4 权限模式

| 模式 | AI 能做什么 | 适合 |
|---|---|---|
| 只建议 | 只提操作卡片，不改工作区 | 第一次用、教学 |
| 先预览（默认） | 在沙盒里试，结果给 AI 看；你点“应用”才改 | 小白 |
| 自动 + 可撤销 | 直接改，每步都能撤销 | 熟练用户、批量 |

### 5.5 和报告、溯源的关系

报告里的每个数字都链接到产生它的操作序列：点“怎么算的”，时间线上对应的卡片高亮，工作区恢复到那一刻的
设置。这样结果可复现，也方便写论文方法部分（“扇区 ±10°，径向 3000 个 bin，SNIP 背景 0.15 Å⁻¹”自动生成）。

## 6. 接入主流 AI

### 6.1 支持的提供方

| 类别 | 提供方 | 接入方式 |
|---|---|---|
| 订阅（不按 token 计费） | Claude Code（Pro / Max） | 本机 `claude -p` + 本地 MCP（已有） |
| 官方 API | Anthropic Claude | 官方 `anthropic` SDK（已有） |
| OpenAI 兼容（官方 `openai` SDK） | OpenAI、DeepSeek、通义千问（DashScope）、Kimi（Moonshot）、智谱 GLM、Google Gemini（兼容端点）、OpenRouter、硅基流动 | 预设 base URL，填 key 即用 |
| 本地 / 私有 | Ollama、LM Studio、vLLM、自建兼容服务 | 填地址，无需 key |
| 企业 | Azure OpenAI | 端点 + 部署名 + api-version |

所有提供方用**同一套工具和提示词**；只要模型支持工具调用（function calling）就能跑完整流程。

- key 按提供方分别保存在用户数据目录（与现在的 Claude key 一样，只本用户可读），也可用各家的环境变量。
- “获取列表”调用 `/models`，模型名不写死（各家更新太快）。
- “测试连接”做一次带工具的最小请求，确认支持工具调用；不支持时明确说“这个模型不能驱动 GIMaP 的工具”。

## 7. 视觉与文案

- **状态色**：绿 = 可信 / 完成，琥珀 = 注意 / 需要回答，红 = 伪影 / 失败，灰 = 未测到；图上用同样的颜色。
- **图示代替术语**：面内 / 面外用一张小示意图（薄膜 + 箭头）；缺失楔、阴影在 q 图上直接标出。
- **文案**：动词开头的按钮（“用这个标定”“掩掉阴影”），不用缩写；数字带单位；不确定的写“≥”“约”并解释。
- **空状态**永远给下一步：不再出现“No geometry yet”这样的死胡同，而是“还没有几何 → [自动查找标定]”。
