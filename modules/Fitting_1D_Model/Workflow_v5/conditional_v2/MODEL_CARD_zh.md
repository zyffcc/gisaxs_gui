# 条件预测 v2 模型说明

这是经验证的条件多候选拟合工作流。输入一条原生 q 曲线、完整组分列表以及两个分辨率参数，返回同组分下多套参数及各自正演曲线。纯神经模式保留18个原始候选；四步模式加入12个数值校正候选，总共30个，再去重排序。候选数量不等于全部可辨识解。

支持 sphere、random_cylinder、vertical_cylinder 三种形状，总组分数1–4，允许重复类型，共34种组合。完整组分和sigma_Res、nu_Res须已知。本次验证限分辨率项开启的模拟数据。不能将它解释为未知组分识别已达89%，也不能把混合权重解释为候选的后验概率。

新版核心使用前向自动微分计算雅可比，在可行参数坐标中固定四轮阻尼Gauss–Newton，每轮保留观测残差更低的候选。只计算活跃形状的正演以减少成本。它仍属于数值校正；纯神经免校正目标尚未完成。原始候选始终保留。

独立128条、每组分数32条，模型及规则先冻结，按观测误差选候选，以clean真值评估：

|模式|clean误差<0.05|<0.03|<0.01|中位|P90|
|---|---:|---:|---:|---:|---:|
|纯神经18候选|84/128|55/128|12/128|0.03483|0.08229|
|神经＋固定四步30候选|114/128|96/128|41/128|0.01558|0.05216|

成对增加30条、丢失0条，达标比例差的bootstrap95%区间为16.41–30.47个百分点。这里的log使用自然对数。已做3840次独立float64候选正演、单位/固定条件/几何约束审计，以及预先指定的每K一条完整CPU重放。4条CPU重放只证明所检查样本的一致性，不是大规模CPU性能测试。

GPU完整逐条调用，首次30.95秒；随后127条中位1.81秒、P90 3.83秒，含模型输出独立正演和去重，不含磁盘输入读取。首次加载与编译明显更慢。本地已验证环境为Windows Python3.10.18、tensorflow-intel2.15.1 CPU、numpy1.26.4、scipy1.15.3、h5py3.16.0。训练及GPU验证在Maxwell既有gisaxs-v5-r2环境完成。对象复用可以避免重复加载。

q及sigma_Res为nm^-1，尺寸R/h/D为nm，分布宽度sigma_R/h/D原始参数是相对标准差，输出同时换算绝对宽度。D与R满足D>=2R×1.001。分辨率项是训练正演中的加性模型，不是任意仪器卷积。强度按训练约定标度，不自动归一化真实数据。输入单位及尺度不匹配会使上述验证结论失效。

真实数据无clean真值时仅给观测logRMSE和按sigma标准化的残差，不设未经噪声校准的“合格”标签。无法从拟合相近推断参数唯一、组分正确或所有参数模式已找到。先前自动微分开发版本在复用开发32条上的有限参考模式覆盖为20/135，仍有明显缺口；当前完整入口独立128没有完整参数模式真值，不能将114/128曲线拟合率当作多解覆盖率。

本包固定运行时代码/权重与独立确认版本一致。报告精度修复仅将计算观测log误差的输入转float64，预测参数与曲线不变；失败首作业24701654及重试24701747均留档，同128身份未重抽。包内model_bundle_precision_r2的旧报告属于历史基础模型，当前v2结论以本文件和VALIDATION为准。正式58文件模型未替换。
